# Chrome Web Store listing

Graphics in this folder are sized for the store: `store-icon-128.png` (96×96 artwork
with 16 px transparent padding), `screenshot-1280x800.png`, `promo-small-440x280.png`
and `promo-marquee-1400x560.png` (24-bit PNG, no alpha). Re-render with
`rsvg-convert store/<name>.svg -o store/<name>.png`, then flatten the alpha onto `#FEF8EC`.

## Description

Wisteria Lily is a warm light theme for Chrome. Wisteria purple accents bloom on a soft day lily cream background, with deep teal text that stays easy on the eyes all day.

It's the browser companion to the Wisteria Lily color theme for Kiro and VS Code, so your editor and your browser finally match.

What you get:
• A cream toolbar and New Tab page with a sandy tab strip
• Wisteria purple tab titles, toolbar icons and New Tab logo
• Deep teal text in the address bar and bookmarks
• A deep teal frame for Incognito windows, so you always know where you are
• Text colors checked against WCAG AA contrast (4.5:1)

Best with Chrome's mode set to Light: open Customize Chrome on the New Tab page and choose Light.

Wisteria Lily for Kiro and VS Code: search for "Wisteria Lily" in the Extensions view.

Source and issues: https://github.com/nikovirtala/wisteria-lily-chrome
